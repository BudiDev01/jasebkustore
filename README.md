# Digital Delight Hub

Create a modern responsive website for selling digital products.

Website requirements:

1. The website must include a Dark Mode and Light Mode toggle that users can switch anytime. The theme preference should be saved automatically.

2. Add a language switcher so users can choose between:

- English

- Bahasa Indonesia

All text on the website must change based on the selected language.

3. User authentication system:

- Sign up using Gmail email and a username

- Support Google Gmail authentication

- Automatic login after successful registration

- Secure login system

- Keep users logged in with session or token system

4. Homepage:

- Modern clean UI design

- Display available digital products in a grid layout

- Categories include:

  - WhatsApp Virtual Numbers

  - Telegram Virtual Numbers

  - Social Media Boosting Services (followers, likes, views)

  - Google Workspace / G Suite accounts

  - Premium subscription apps

  - Other digital services

5. Product system:

Each product should display:

- Product name

- Price

- Description

- Buy button

6. Payment page:

- When a user clicks the buy button, redirect to a single payment page

- Display my QRIS GoPay Merchant QR code

- Show simple payment instructions

- After payment, show a confirmation message

7. WhatsApp support button:

- Add a floating WhatsApp icon on the bottom-right corner of the website

- When clicked, it should open WhatsApp chat directly with the admin number

- The chat message can include a default text like: "Hello Admin, I need help with your digital products."

8. Optional user dashboard:

- User profile

- Purchase history

- Purchased products

9. Design requirements:

- Modern SaaS style interface

- Mobile responsive

- Fast loading

- Clean and minimal design

10. Technology:

- Use modern web technologies (HTML, CSS, JavaScript, React or Next.js)

- Backend using Node.js or Firebase

- Securely store user data

Output:

Provide full project structure and complete code needed to run the website.
